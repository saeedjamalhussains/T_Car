T-Car carrier & gateway lookup

Paste anything — a CSV, a contact list, an email. Every phone number in it, anywhere in the world, gets looked up. Write international numbers with a +.

Everything this app knows, as it is stored. A lookup is nothing more than a row out of these tables — browsing them shows exactly how much (and how little) a prefix-block database can tell you.

Providers run top to bottom until one answers. Only offline returns data in this demo; the rest are the 2014 originals, kept for study. Credentials stay on this device (~/.config/tcar/config.json) and are never sent anywhere else.

About

Educational demo. This app exists to show how carrier and SMS-gateway lookup works. Answers come from one offline North American dataset from 2014; the four services the original scraped are included unchanged as study material and no longer return data. Do not rely on any of it for billing, routing, fraud, compliance, or anything touching a real person's service. Phone numbers are personal data — handle them under your local law.

A rebuild of node-tel-carrier (AJ ONeal, 2014) as a native cross-platform app: Rust core, Tauri shell, one binary per OS.

Worldwide numbers

Any E.164 number parses and formats correctly, worldwide. Carrier data does not follow: the bundled database and the email-to-SMS gateway addresses are North America only, because those were the only datasets the 2014 project had.

Full version

Working worldwide lookups — live scrapers, commercial API integrations, updated gateway data, and an HNI/MCC-MNC database — are not part of this educational demo. For that, email projectsjh18@gmail.com.

    What changed

    • Worldwide E.164 parsing instead of one permissive North American regex.
    • Offline prefix database embedded — lookups work with no network.
    • The 2014 services kept intact, each labelled with whether it can still answer.
    • A Data tab that opens the bundled tables up for inspection.
    • No analytics upload. The original POSTed every number it saw to a third-party host.
